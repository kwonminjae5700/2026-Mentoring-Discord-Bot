# ☕ 멘토링 예약 Discord 봇

방장(멘토)이 멘토링 가능한 시간을 열어두면, 멤버들이 캘린더에서 날짜·시간을 골라 1:1로
예약하는 봇이에요. 예약은 **① 시간 예약 → ② 만나기 하루 전까지 "나누고 싶은 말" 작성**
2단계로 흘러요.

## 주요 기능

- 멘토가 멘토링 가능 시간(슬롯)을 하나씩 열기 (`/슬롯추가`)
- 멤버는 월간 캘린더에서 날짜 선택 → 그 날의 빈 시간만 버튼으로 표시
- 한 시간엔 한 명만 예약, 이미 찬 시간은 **회색 비활성**
- 예약/취소 자유롭게 (에페메랄로 나만 보임)
- 예약하면 멘토에게 **DM 알림**, 멘티에겐 확인 메시지
- 만나기 하루 전까지 "나누고 싶은 말"(마크다운) 미작성 시 멘티에게 **재촉 DM**
- "나누고 싶은 말" 제출 시 멘토에게 **내용 DM**

## 설치 & 실행

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 설정
cp .env.example .env
#   .env 를 열어 토큰/ID 채우기

# 3. 슬래시 명령 등록 (서버에 즉시 반영)
npm run deploy

# 4. 봇 실행
npm start
```

### .env 채우는 법

| 변수 | 설명 |
|------|------|
| `DISCORD_TOKEN` | Developer Portal → Bot → Token |
| `CLIENT_ID` | Developer Portal → General Information → Application ID |
| `GUILD_ID` | 봇이 동작할 서버 ID (개발자 모드로 서버 우클릭 → ID 복사) |
| `MENTOR_USER_ID` | 멘토(방장) 본인의 유저 ID. 이 사람만 슬롯 관리 + 알림 DM 수신 |
| `PANEL_CHANNEL_ID` | (선택) 미사용 가능 |
| `TIMEZONE` | 기본 `Asia/Seoul` |

### 봇 초대 시 권한

- 스코프: `bot`, `applications.commands`
- 권한: 메시지 보내기(패널 게시용) 정도면 충분해요. 특권 인텐트는 필요 없어요.

## 명령어

| 명령 | 권한 | 설명 |
|------|------|------|
| `/슬롯추가 날짜 시작 종료` | 멘토 | 시간 1개 열기 (예: `2026-06-03 19:00 20:00`) |
| `/슬롯목록` | 멘토 | 열어둔 시간·예약 현황 보기 / 삭제 |
| `/멘토링패널` | 멘토 | 현재 채널에 신청 패널 게시 |
| `/내멘토링` | 전원 | 내 예약 보기 / 나누고 싶은 말 작성·수정 / 취소 |

## ⚠️ DM 알림 주의

신청 알림·재촉·메시지 도착 알림은 모두 **DM**으로 가요. 동작하려면:

- 멘토와 멘티가 봇과 **같은 서버**에 있어야 하고,
- 서버 설정에서 **DM 허용**이 켜져 있어야 해요.

DM이 막혀 있으면 재촉은 멘토에게 폴백 보고돼요.

## 구조

```
src/
  index.js            진입점 (이벤트 라우팅)
  config.js / time.js 설정 · KST 시간 헬퍼
  db.js               SQLite (slots / bookings)
  deploy-commands.js  슬래시 명령 등록
  commands/           슬롯추가 · 슬롯목록 · 멘토링패널 · 내멘토링
  interactions/       버튼·드롭다운·모달 라우터
  ui/                 calendar · slots · embeds (토스풍 카피)
  scheduler.js        하루 전 재촉 (매시 정각)
data/                 sqlite 파일 (자동 생성)
```
